# consistent-pet
This repo uses a 96gb blackwell to take referance images of pets and uses an ai model to rescore it. 


## Portrait reference library

[Browse the725-reference library](reference-library/README.md): full-resolution masters grouped by male/female/unisex and63 categories, searchable local gallery, prompts, hashes and100 vintage poster variants. [Hugging Face mirror](https://huggingface.co/datasets/bensblueprints/consistent-pet). Run `git lfs pull` to download the actual images.
